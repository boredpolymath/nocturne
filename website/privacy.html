3. Technical Operation & System Interactions

Because Nocturne is an interactive desktop companion that responds when your workstation falls quiet in the late hours, we explain exactly what OS APIs it calls:

A. Aggregate Idle Time Counters (No Keylogging)

To know when to trigger ambient manifestations, Nocturne must know whether you are actively using your computer. It accomplishes this solely by querying aggregate operating system idle counters:

  • Windows: GetLastInputInfo (Win32 user32 API)
  • macOS: CGEventSourceSecondsSinceLastEventType (CoreGraphics API)
  • Linux: XScreenSaverQueryInfo (libXss / X11)

Privacy Guarantee: These OS counters provide only a single aggregate number: how many seconds or milliseconds have elapsed since any generic hardware input was registered. They cannot read what you typed, what you clicked, which applications you were using, or what appeared on your screen.

B. Emergency Panic Failsafe (Triple-ESC Purge)

Nocturne provides an instant hardware failsafe allowing you to tap ESC three times rapidly to immediately silence audio, reset display color temperatures, and disengage background processing.

Privacy Guarantee: The emergency failsafe hook filters exclusively for keycode 0x1B (the standard Escape key) within an ephemeral in-memory 3-slot monotonic ringbuffer. Every other keystroke is immediately ignored and discarded unread without being buffered, logged, or analyzed.

C. Display Color Ramp Adjustments

During subtle manifestation phases, Nocturne gently adjusts monitor color-temperature ramps using native operating system gamma lookup tables (Windows GDI SetDeviceGammaRamp / macOS CoreGraphics display tables).

Privacy Guarantee: These are strictly outbound hardware LUT commands clamped to safe luminance thresholds (≤ 8% delta). Nocturne never reads pixels from your screen, captures window bitmaps, or records display content.

D. Real-Time Procedural Audio DSP

Nocturne produces binaural sound phenomena (such as floorboard creaks, CRT hums, and spirit-box whispers) via mathematically generated oscillators running at 48 kHz stereo in pure Rust.

Privacy Guarantee: No pre-recorded media files are downloaded from the web, and no audio input device is ever accessed.

4. Local-First Storage & Data Retention

Nocturne stores minimal operational records entirely on your local machine:

  • Simulation Incident Log (nocturne_telemetry.db): Contains purely simulated event records (e.g., timestamps of triggered sound phenomena, simulated EMF milligauss levels, simulated cold-spot temperatures, and session start/end).
  • File Locations:
    • Windows: %LOCALAPPDATA%\com.nocturne.app\nocturne_telemetry.db
    • macOS: ~/Library/Application Support/com.nocturne.app/nocturne_telemetry.db
    • Linux: ~/.config/nocturne/nocturne_telemetry.db
  • Rolling Cap: The local database enforces a rolling cap of 10,000 incident rows; older records are automatically pruned.
  • Access Permissions: On Unix systems, files are created with 0600 permissions (accessible only by the active user account) and directories with 0700.

How to Delete Your Data: You can purge all stored records at any time simply by deleting the nocturne_telemetry.db file or uninstalling the application. Because zero data is ever uploaded to our servers, local deletion is immediate, complete, and permanent.

5. Air-Gap Architecture & Zero Network Egress

Nocturne enforces an uncompromised air gap:

  • Prohibited Dependencies: HTTP and network client crates (including reqwest, hyper, curl, ureq, openssl, rustls, and tauri-plugin-http) are explicitly banned in deny.toml and verified on every commit.
  • Runtime Socket Scrubber: The AirGapEnforcer routine checks open POSIX file descriptors at startup to ensure zero AF_INET or AF_INET6 network sockets are instantiated.
  • Strict Content Security Policy: The user interface is locked down with default-src 'self'; connect-src 'none'; frame-src 'none'; object-src 'none'.
  • OS Sandboxing: On macOS, Nocturne executes inside an isolated Apple Seatbelt profile (nocturne-airgap.sb) that categorically denies network operations.
